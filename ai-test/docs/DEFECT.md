# AI-DEF-001：原始模型忽略绝对边界，建议不可执行的动作

这是本次新增 AI 建议器的模型单独输出模式（raw）在实验中的实际问题。raw与guarded共享同一模型、同一输入和同一断言，只切换是否经过动作安全过滤。它是可复现的基线/改进对照，不冒充原模块一发现的缺陷或历史发布版本。

- 关联用例：AI22；AI23为其他边界的同根因回归，不另计缺陷。
- 严重性建议：中。若直接消费建议会产生非法动作；原游戏的移动限界可能使玩家停在原地，实际影响须在集成后验证。
- 输入：player位置(0,400)，尺寸77×53，速度9，grade=3；强鱼位于(300,400)，grade=1，state=1。
- 预期：最终动作不会把玩家带出画布。
- raw实际：action=LEFT，raw_action=LEFT，confidence=1.0，reason=model。执行建议后x=-9，断言失败。
- 根因：模型仅见相对坐标和目标类别，不包含玩家绝对位置与画布边界。3/3一致投票也不意味着动作安全。
- 修复：在动作执行前枚举和过滤非法下一步，保留raw_action用于诊断；不修改测试预期，不用提高准确率掩盖边界问题。
- 验证：同一模型的guarded模式通过AI22及全量30条；完整raw对照失败4条、错误0条、跳过0条。

复现与回归命令：

```console
python run_tests.py --variant raw --case test_AI22_left_boundary
python run_tests.py --case test_AI22_left_boundary
python run_tests.py
```

完整对照证据在 `reports/raw/results.json` 和 `reports/guarded/results.json`，按用例ID可找到输入、输出和失败堆栈。具体环境、时间和模型摘要见JSON，文档不虚构成员、提交号或人工复核签字。

其他实验观察：AI24表明只看最近威胁可能撞向第二威胁；AI25表明没有退路时原始模型仍给出行动方向。当前过滤器能处理测试中的场景，但不代表动态环境的缺陷已全部消除。400条留出样本另有27个方向分类错误（93.25%准确率），保留在报告中，未声称训练已修复全部分类错误。
