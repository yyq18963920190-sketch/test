# 设计与可解释范围

## 被测模型

kNN 是监督学习中的惰性学习算法：训练阶段保存带标签的样本，推理阶段计算距离、选取3个最近邻并投票。本项目以1600条合成专家示例拟合分类器，不调用外部服务，不把固定的模拟响应冒充模型。模型文件包含全部训练样本、随机种子、特征名、k及schema。

特征为最近目标相对坐标 dx/1900、dy/1900 和威胁类别（+2/-2）。优先选强鱼作为目标，没有强鱼时选可捕食鱼；这是明确的特征工程。训练标签遵循“追逐弱鱼、远离强鱼，沿主要坐标轴移动”的专家策略。动作本身由最近邻投票决定。

训练随机种子20260920，留出集种子75119。留出集不参与训练，测试验证特征没有与训练集完全重合。测试判定用动作向量点积独立实现方向oracle；训练用主坐标轴规则。两者表达同一行为契约，仍存在合成规则来源相同、分布过于简单的局限，不能等同于真实玩家数据或真实游戏泛化能力。

## 输入及输出约定

输入包含 player 字典和 fish 列表。player 必填 x/y/width/height/speed/grade/state；fish 各项必填 x/y/width/height/grade/state。示例见 data/example.json。所有数值必须有限，bool不当作数值；grade是1–4整数，非玩家鱼state为0/1。player的state仅1允许推理，其他0/2/3/4全部暂停建议。

画布为1900×980，坐标为左上角；玩家完整矩形须在画布内；宽1–220、高1–150、单步速度0–100，最多200条鱼。非玩家鱼允许从画外生成（x=-300至2200，y=-150至1130）。这些容量和数值限制是新增建议器的输入契约，不是附件中的强制规定。

输出为 action、raw_action、confidence、reason。confidence是3个邻居的投票比例，**不是经过校准的正确概率**。无模型调用时raw_action为null。不接受模型输出作弊动作，不允许直接修改分数或排行榜。

## 安全过滤及边界

过滤器枚举5个动作，检查玩家矩形仍在场内且下一步不与任何活着的强鱼矩形重叠。保留合法原始动作；否则选安全候选中离威胁中心最远的动作。没有候选时返回STAY和no_safe_action，明确表示无法保证安全，而非成功逃生。

安全过滤只检查静态快照的一步终点，未建模敌鱼运动和运动路径，不保证长期存活；速度较高时仍可能穿过中间障碍。这里的保守矩形碰撞不同于原Java代码的按等级缩进碰撞，因此不是Java碰撞算法的逐像素复刻。玩家边界允许恰好贴边，原Fish.move使用严格不等式；集成时需统一契约。

## 测试分层与AI反思

原始分类模型指标、输入处理和安全过滤分别检查。30个方法是自动化用例数，循环内的400个样本、90对反事实等是评估数据量，不能当作额外独立用例重复计数。测试重复调用用于检查确定性，不是统计独立试验，不据此给出置信区间。

默认模式全绿是“达到明确阈值且防护满足测试场景”的结果，并非AI完美。公平性只涉及输入字段独立性，未证明人口统计群体实际受益相同。由于推理不使用文本，无需LLM裁判；不用主观字符串相似度判分。后续值得增加真实游戏轨迹、动态威胁、对角线临界点、每局存活时间及反事实配对覆盖。

本次只使用Python标准库，因此不需要第三方依赖锁文件；报告记录具体Python版本、操作系统与模型摘要。模型摘要用于定位版本，不是签名认证；格式校验不保证模型来源可信。
